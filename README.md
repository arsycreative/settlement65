# Settlement65 — Final Settlement and Distribution Portal

Official web portal for **Settlement65** (`settlement65.com`).

Settlement65.com provides a central online point of access for members during the concluding stage of the program. Following completion of the program's principal activities, the remaining focus is on addressing outstanding settlement and distribution matters in accordance with applicable records and procedures.

## Key Features

- **Institutional Design System**: Custom Obsidian Slate & Imperial Champagne Bronze styling.
- **Dual Adaptive Themes**: High-contrast dark and executive light mode.
- **5 Structured Sections**:
  1. The Final Settlement and Distribution Phase
  2. Settlement Administration and Verification
  3. Distribution Processing and Timing
  4. Communications and Member Records
  5. Member Access and Inquiries & Member Login Facility
- **Performance & SEO**: Built with Next.js App Router, SSR/SSG, automated metadata, sitemap, and Netlify hosting optimizations.

## Getting Started

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the portal.
